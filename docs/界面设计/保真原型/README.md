## 如何查看

- 直接用浏览器打开 `pages/00-index.html`（导航封面，可跳转全部 8 页）。
- 或在本目录起静态服务：`python3 -m http.server 8999`，访问 `http://localhost:8999/pages/00-index.html`。
- `screenshots/` 为 1440×900 @2x 的 Chromium 无头自检截图，不打开浏览器也可快速过稿。

## 原型与正式实现的边界

- 数据均为静态模拟；所有交互（跳转除外）只做视觉表达，不接后端。
- 原型外壳只保留新 IA 的菜单；旧页面（数据源管理、用户与权限、操作审计等）在正式实现中原地保留并归位。
- `echarts-theme.js` 与 `shell.js` 是原型脚手架，不复用进生产；正式组件遵循文档驱动开发指南的 Props/Emits/Store 规范。
