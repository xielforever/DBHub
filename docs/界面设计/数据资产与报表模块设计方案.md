## 1. 设计目标与范围

在不改变技术栈（Go + Vue3 + Element Plus + ECharts + Postgres）与视觉体系（液态玻璃暗色规范）的前提下，补齐调研确认的两个高优模块，并收口 IA 红线问题：

| 编号 | 模块 | 对应调研报告 | 本批范围 |
| --- | --- | --- | --- |
| A | **数据资产 / 数据地图（轻量版）** | M6、M2 | 元数据采集落库、资产目录、全局搜索、表详情（字段/索引/外键/DDL/预览/血缘）、Owner/标签/分级/注释/热度 |
| B | **查询结果图表化 + 报表中心（轻量版 BI）** | M5 | 结果一键转图（4 类图表）、保存报表、个人/共享仪表盘、只读分享链接 |
| C | **IA 收口** | M13 | 全局搜索落地、通知铃铛隐藏（待通知中心）、设置入口去重、菜单分组调整 |
| D | **表数据管理（P0，仅出图预研）** | M3/M4 | 数据网格行内编辑、改动暂存、生成 SQL 预览与风险校验、二次确认 |
| — | Monaco、AI、导入导出、工单审批、脱敏、监控、调度 | M3/M7/M8/M9/M10/M11 | **本批不做**，仅在 IA 上预留位置（见第 3 节） |

设计原则：
1. 每个菜单项必须有真实路由与页面（延续"禁止假链接"红线）；
2. 新模块全部沿用现有查询通道与 RBAC，不新建鉴权体系；
3. 资产/报表数据模型可被后续脱敏、工单、监控复用，不做一次性设计。

### 3.3 与既有页面的边界

- **数据源管理**：连接参数、凭据、SSH 隧道（"怎么连"，IT 视角）；

- **SQL 工作台**：临时查询与一次性结果；

从工作台结果"另存为报表"后即进入报表中心；从资产详情"去查询"跳到工作台并自动定位该表。

## 4. 数据模型（DDL 草案，评审用）

> 全部为平台元数据库（`sys_`/新前缀）表，与业务库无关；幂等迁移脚本随开发提交。
> 命名延续 `sys_` 前缀；分区、审计字段约定沿用既有迁移。

```sql
-- 4.1 元数据采集快照（同步字典）
CREATE TABLE sys_meta_snapshots (
  id              BIGSERIAL PRIMARY KEY,
  connection_id   BIGINT NOT NULL REFERENCES sys_connections(id) ON DELETE CASCADE,
  database_name   VARCHAR(128) NOT NULL,
  schema_name     VARCHAR(128) NOT NULL DEFAULT '',
  table_name      VARCHAR(128) NOT NULL,
  table_type      VARCHAR(16) NOT NULL DEFAULT 'table',   -- table | view
  table_comment   VARCHAR(512) NOT NULL DEFAULT '',        -- 来源库原生注释
  estimated_rows  BIGINT NOT NULL DEFAULT 0,
  data_bytes      BIGINT NOT NULL DEFAULT 0,
  raw_columns     JSONB NOT NULL DEFAULT '[]',             -- 列结构快照
  raw_indexes     JSONB NOT NULL DEFAULT '[]',
  raw_keys        JSONB NOT NULL DEFAULT '[]',             -- 主键/外键
  ddl_text        TEXT NOT NULL DEFAULT '',
  synced_at       TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE(connection_id, database_name, schema_name, table_name)
);
CREATE INDEX idx_meta_snap_conn ON sys_meta_snapshots(connection_id);

-- 4.2 人工标注（业务元数据，与快照分离，重新采集不覆盖人工内容）
CREATE TABLE sys_asset_annotations (
  id              BIGSERIAL PRIMARY KEY,
  connection_id   BIGINT NOT NULL REFERENCES sys_connections(id) ON DELETE CASCADE,
  database_name   VARCHAR(128) NOT NULL,
  schema_name     VARCHAR(128) NOT NULL DEFAULT '',
  table_name      VARCHAR(128) NOT NULL,
  column_name     VARCHAR(128) NOT NULL DEFAULT '',         -- 空串=表级标注
  owner_user_id   BIGINT REFERENCES sys_users(id),
  business_desc   VARCHAR(1000) NOT NULL DEFAULT '',
  tags            TEXT[] NOT NULL DEFAULT '{}',
  sensitivity     VARCHAR(16) NOT NULL DEFAULT 'normal',   -- normal | sensitive | confidential
  starred_by      BIGINT[] NOT NULL DEFAULT '{}',          -- 收藏用户
  updated_by      BIGINT,
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE(connection_id, database_name, schema_name, table_name, column_name)
);

-- 4.3 报表（一张图表 = 一次保存的查询 + 图表配置）
CREATE TABLE sys_reports (
  id              BIGSERIAL PRIMARY KEY,
  name            VARCHAR(128) NOT NULL,
  description     VARCHAR(512) NOT NULL DEFAULT '',
  connection_id   BIGINT NOT NULL REFERENCES sys_connections(id) ON DELETE CASCADE,
  database_name   VARCHAR(128) NOT NULL,
  sql_text        TEXT NOT NULL,
  chart_type      VARCHAR(16) NOT NULL DEFAULT 'table',    -- table | bar | line | pie | metric
  chart_config    JSONB NOT NULL DEFAULT '{}',             -- 维度/指标/聚合/排序/颜色
  visibility      VARCHAR(16) NOT NULL DEFAULT 'private',  -- private | shared
  owner_user_id   BIGINT NOT NULL REFERENCES sys_users(id),
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 4.4 仪表盘（报表的有序组合）
CREATE TABLE sys_dashboards (
  id              BIGSERIAL PRIMARY KEY,
  name            VARCHAR(128) NOT NULL,
  description     VARCHAR(512) NOT NULL DEFAULT '',
  visibility      VARCHAR(16) NOT NULL DEFAULT 'private',
  layout          JSONB NOT NULL DEFAULT '[]',             -- [{report_id,x,y,w,h}]
  owner_user_id   BIGINT NOT NULL REFERENCES sys_users(id),
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 4.5 只读分享链接（复用平台令牌签发能力，独立短令牌）
CREATE TABLE sys_share_tokens (
  id              BIGSERIAL PRIMARY KEY,
  subject_type    VARCHAR(16) NOT NULL,                    -- report | dashboard
  subject_id      BIGINT NOT NULL,
  token_hash      VARCHAR(128) NOT NULL UNIQUE,            -- 仅存哈希
  created_by      BIGINT NOT NULL,
  expire_at       TIMESTAMPTZ,                             -- NULL=永不过期
  revoked         BOOLEAN NOT NULL DEFAULT FALSE,
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

补充说明：
- **热度不建表**：表/库查询次数、Top 用户由 `sys_query_history` 实时聚合（近 7/30 天），零冗余；
- **血缘不建图数据库**：v1 从 `sys_query_history.sql_text` 用 SQL 解析器离线提取表级依赖（PG 用 `pg_query_go`，MySQL 用 `vitess/sqlparser`，二者均为 Go 库，vendored），结果缓存到 `sys_meta_lineage`（表级）；字段级血缘列入 P3；
- 资产标注表为未来 M9 动态脱敏直接复用（`sensitivity` + 列级行已预留）。

## 5. API 契约草案

沿用统一响应壳 `{code,message,data}` 与三通道鉴权；写操作按现有路由中间件限 admin/developer。

### 5.1 元数据采集与资产
| 方法 & 路径 | 说明 |
| --- | --- |
| `POST /api/v1/assets/sync?connection_id=` | 触发"同步字典"：拉库/schema/表/列/索引/DDL/行数估算，落快照；后台任务，返回 jobId（v1 可同步执行） |
| `GET /api/v1/assets/tree` | 资产左树（数据源→环境→库→schema→表），支持 `&keyword=` |
| `GET /api/v1/assets/tables?connection_id=&database=&schema=&keyword=&tag=&sensitivity=&page=&page_size=` | 资产列表（含快照统计 + 标注 + 近30天热度） |
| `GET /api/v1/assets/table/detail?connection_id=&database=&schema=&table=` | 表详情聚合：快照列/索引/外键/DDL + 标注 + 热度 + Top 用户 |
| `PUT /api/v1/assets/annotations` | 保存 Owner/说明/标签/分级（表级与列级） |
| `POST /api/v1/assets/star` / `DELETE /api/v1/assets/star` | 收藏/取消 |
| `GET /api/v1/assets/lineage?connection_id=&database=&schema=&table=` | 表级上下游血缘 |
| `GET /api/v1/assets/search?q=&type=table|column|report|history` | **全局搜索**（顶栏，混合分组返回） |

### 5.2 报表与仪表盘
| 方法 & 路径 | 说明 |
| --- | --- |
| `POST /api/v1/reports/preview` | 体 `{connection_id,database,sql,chart_config}`：执行 SQL（只读/写角色同权，写语句照旧拦截）+ 返回行列与图表渲染结果，不保存 |
| `POST /api/v1/reports` / `PUT /api/v1/reports/{id}` / `DELETE /api/v1/reports/{id}` | 报表 CRUD |
| `GET /api/v1/reports?scope=mine|starred|shared` | 报表中心列表 |
| `POST /api/v1/dashboards` / `PUT /api/v1/dashboards/{id}` / `GET /api/v1/dashboards/{id}` | 仪表盘 CRUD 与详情（含各报表最新数据） |
| `POST /api/v1/shares` / `DELETE /api/v1/shares/{id}` | 创建/吊销分享链接 |
| `GET /api/v1/shared/{token}` | **免登录只读渲染**所需的数据接口（仅该令牌范围内资源，走独立中间件，不计入个人额度） |

### 5.3 表数据管理（D 预研，接口在 P0 实施时细化）
- `GET /data/preview` 已有，增加排序/列筛选参数；
- `POST /api/v1/data/changes/preview`：提交单元格改动，返回分类后的 INSERT/UPDATE/DELETE 语句与风险检查结果（是否有 WHERE、影响行数预估、是否命中无主键表）；
- `POST /api/v1/data/changes/commit`：在单事务内执行，返回每条成功/失败；readonly 角色 403。

## 6. 关键交互设计

### 6.1 数据资产页（图 01）
- 三栏：左资产树（固定 264px，可折叠，含"收藏""全部资产"虚拟节点 + 按数据源分组）→ 主列表；
- 顶部全局搜索（全站顶栏）输入即搜，下拉分四组：**表/视图、字段、报表、查询历史**，键盘 ↑↓ 选择、Enter 跳转，高亮命中片段；搜索即资产页主入口，消化当前假搜索框；
- 列表列：表名（类型图标）/ 所属路径 / Owner / 标签 / 分级徽标 / 行数 / 近 30 天查询次数（带迷你热度条）/ 最近同步时间；行点击进详情；
- 空状态：未采集时显示「该数据源尚未同步资产目录 → 立即同步字典」引导；
- 同步状态：连接名旁显示绿点（已同步）/琥珀（30 天未更新）/灰（未采集）。

### 6.2 表详情（图 02、03）
- 面包屑：数据资产 / 数据源 / 库 / schema / 表名；
- 操作：收藏、在工作台打开、复制表名、导出 DDL；
- Tabs：字段（含类型/可空/主键/默认值/原生注释/**业务说明（行内编辑）**/**敏感分级**）、索引、外键、DDL（代码块+复制）、数据预览（复用现有分页，阶段 D 后可编辑）、血缘；
- 右侧信息栏：Owner（下拉指定）、业务说明、标签、分级（普通/敏感/机密 三档徽标与配色）、技术统计（行数/容量/索引数/同步时间）、近 30 天查询趋势迷你图、Top 查询者；
- 血缘 Tab：居中 SVG 图，节点为表（显示关键列），连线带箭头与类型标签（SELECT→写入 / JOIN）；左上游、右下游；点击节点跳转；右侧影响分析列出"上游 N 表 / 下游 N 报表·N 查询"。

### 6.3 工作台 → 图表（图 04）
- 结果区在「数据/历史/Redis/消息」前插入 **图表** Tab；SQL 执行成功后自动判断列类型并给出推荐（维度列 + 数值列）；
- 图表配置条（轻量，不做完整 BI）：图表类型（柱/折/饼/数值卡 4 选 1，表格为默认）、维度（1 列）、指标（多列 + sum/count/avg/min/max）、排序、Top N；
- 配置变化即时出图（复用项目已有 ECharts 组件，柱/折/饼与仪表盘图表风格统一）；
- 右上动作：**另存为报表**（弹窗：名称、所属仪表盘（可新建）、可见范围）；只读角色可保存个人报表；
- 不在工作台做仪表盘布局编辑，避免与报表中心职责重叠。

### 6.4 报表中心与仪表盘（图 05、06）
- 报表中心三段：收藏置顶、我的报表、共享给团队；卡片为图表缩略图 + 名称 / 数据源 / 更新时间 / 所有者；
- 仪表盘查看：顶部标题、时间筛选（v1 固定 SQL 原样执行，时间筛选为 P2 参数化）、网格布局（24 栅格，卡片可拖动，编辑态）；
- 分享：右上「分享」弹层 → 生成只读链接（带有效期选项：7 天/30 天/永久）、一键复制、吊销列表；免登录页面去掉应用侧边栏，仅渲染该仪表盘并标注只读水印位（P2）。

### 6.5 表数据管理（图 07，P0 预研）
- 资产详情「数据预览」或工作台表预览进入**编辑模式**（写角色可见开关，readonly 不显示）；
- 单元格双击编辑，新增行、勾选删除；改动行琥珀色高亮、未提交前不触库；
- 底部浮动变更条：`N 项待提交变更 · 预览 SQL · 放弃 · 提交`；
- 右侧抽屉展示自动生成的参数化语句清单 + 风险检查：无 WHERE 的 UPDATE/DELETE 红色阻断、影响行数 > 阈值黄色确认、无主键表提示；提交后逐条回显结果，失败可定位行；
- 全程单事务，失败整体回滚。

## 8. 风险与取舍

1. **元数据采集的实时性 vs 成本**：v1 手动 + 连接保存后触发同步；行数用 `pg_class.reltuples`/`information_schema.tables.table_rows` 估算值，不做 COUNT(*)；定时同步放阶段二；
2. **SQL 解析血缘**：仅解析平台内执行过的 SQL（历史表），不做数据库侧 binlog/WAL 血缘，覆盖"常用资产"足够，成本低；解析失败降级为"无血缘"，不阻塞；
3. **报表 SQL 安全**：报表执行复用 `/query/execute` 全部约束（单语句、1000 行、只读写拦截、全量审计）；分享链接仅可读取、仅命中固化 SQL，不接受任意参数（P2 再加白名单参数）；
4. **不做成 BI 平台**：不做数据集建模、下钻、透视表、大屏、Excel 导入；超出 4 类图表/单维度的需求引导导出后用专业 BI；
5. **不做完整数据治理**：无术语表、数据质量规则、数据剖析、字段级血缘（P3 评估）；
6. 资产标注初期靠人工，Owner 默认取连接创建人，降低冷启动成本。

1. **M1（P0）IA 收口 + 数据底座**：菜单/设置/铃铛调整；`sys_meta_snapshots` 等迁移；同步字典任务；资产后端接口；
