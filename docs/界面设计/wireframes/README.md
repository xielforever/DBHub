# DBHub 低保真 UX 线框图（Lo-Fi Wireframes）

> 本目录为开发前的低保真交互稿，用于确认**信息层级、布局结构与操作路径**，
> 不代表最终视觉。最终视觉请遵循 [UI设计规范.md](../UI设计规范.md) 的液态玻璃设计语言。

## 设计稿清单

### 1. 登录页 `01-登录页.png`
- 居中玻璃卡片：品牌标识 → 欢迎语 → 用户名/密码输入 → 记住我/忘记密码 → 主登录按钮
- 底部状态栏展示后端服务状态与版本号
- 错误态：用户名/密码错误统一提示「用户名或密码错误」，防止账号枚举
- 交互：登录成功后按 `redirect` 参数跳转，默认进入仪表盘

### 2. SQL 工作台 `02-SQL工作台.png`（核心页面）
四区式 IDE 布局：
1. **一级图标导航栏**：仪表盘 / 数据源 / 工作台 / 审计 / 设置
2. **连接树面板**：服务器 → 数据库 → 表/视图分组 → 数据表，支持搜索与懒加载
3. **中央工作区**：
   - 多标签 SQL 编辑器（后续集成 Monaco Editor）
   - 工具栏：运行按钮、目标数据库选择、LIMIT 设置
   - 底部结果面板：`结果 / 消息` 双标签、数据网格、状态栏（执行耗时、行数）
4. **AI 助手面板**：可折叠，承担 SQL 生成、执行计划解释与优化建议

### 3. 仪表盘 `03-仪表盘.png`
- 顶部：面包屑、全局搜索、通知、用户菜单
- KPI 卡片行：数据源总数、今日查询数、活跃会话、审计事件（含迷你走势）
- 图表行：查询趋势折线图（ECharts）、数据源类型环形图
- 底部：最近查询历史表格

### 4. 数据源管理 + 新建连接弹窗 `04-连接管理与新建弹窗.png`
- 数据源卡片网格：类型图标、名称、host:port、连接状态、查询/编辑/删除操作
- 顶部搜索 + 类型筛选 + 「新建连接」按钮
- 新建连接弹窗表单：
  - 基本信息：连接名称、数据库类型（MySQL/PostgreSQL/Redis）
  - 连接信息：主机、端口、默认库、用户名、密码（标注 AES-256-GCM 加密存储）
  - SSL 模式选择
  - 可折叠 SSH 隧道区：启停开关、跳板机主机/端口/用户名/认证方式（密码/私钥）
  - 底部操作：测试连接 / 取消 / 保存

### 5. 操作审计 `05-审计日志.png`
- 筛选栏：日期范围、操作类型下拉、用户/资源关键词、导出
- 表格列：时间、用户、操作（标签）、资源类型、资源名称、IP、状态、耗时
- 行可展开查看参数快照（JSON）；底部分页

## 全局交互约定
- 登录态失效（401）：自动清空本地令牌并跳转登录页，携带 `redirect`
- 所有危险操作（删除、登出）需二次确认
- 长耗时操作提供进度反馈，按钮进入 loading 态防止重复提交
- 空状态使用 Element Plus Empty 组件配引导操作
