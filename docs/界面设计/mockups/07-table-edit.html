① 新增 · INSERT（参数化）

③ 删除 · DELETE（外键级联）
DELETE FROM order_items WHERE order_id = $1; -- 级联 12 行 DELETE FROM shop.orders WHERE id = $3;
全部语句均为参数化 SQL，无字符串拼接
UPDATE / DELETE 均以主键 id 作为 WHERE 条件
DELETE 将级联删除 order_items 12 行（ON DELETE CASCADE），提交时二次确认
预计影响 14 行，超过管理员设定阈值（10 行），需填写变更原因
无 WHERE 的全表 UPDATE/DELETE 将被直接阻断（示例：禁用态）
同一事务提交，任一语句失败整体回滚；提交记录写入操作审计
