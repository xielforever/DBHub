# 数据库设计 (Metadata Schema)

## 云端补齐：迁移 0013–0016

`sys_sql_snippets`：`id BIGSERIAL PK`，`user_id BIGINT NOT NULL FK sys_users(id) ON DELETE CASCADE`，`name VARCHAR(200) NOT NULL`，`sql_text TEXT NOT NULL`，`database_name VARCHAR(200) NOT NULL DEFAULT ''`，`connection_id BIGINT NULL FK sys_connections(id) ON DELETE SET NULL`，`visibility VARCHAR(20) CHECK private/shared`，创建/更新时间均 `TIMESTAMPTZ NOT NULL DEFAULT NOW()`；索引 `(user_id,visibility)`。

`sys_query_policies`：`id BIGSERIAL PK`，`connection_id BIGINT FK sys_connections(id) ON DELETE CASCADE`，数据库/schema/表名 `TEXT NOT NULL`，`role_code VARCHAR(30) FK sys_roles(code)`，`column_permissions JSONB DEFAULT '{}'`，`row_conditions JSONB DEFAULT '[]'`，`updated_by BIGINT FK sys_users(id)`，`updated_at TIMESTAMPTZ`；连接、数据库、schema、表、角色联合唯一。

`sys_query_settings`：`user_id BIGINT PK/FK sys_users(id) ON DELETE CASCADE`，`timeout_ms INTEGER DEFAULT 30000 CHECK 1000..120000`，`max_rows INTEGER DEFAULT 1000 CHECK 1..10000`，`block_unsafe_write BOOLEAN DEFAULT TRUE`，`updated_at TIMESTAMPTZ`。

完整 DDL 以 [0013_backend_completion.sql](../../backend/internal/db/migrations/0013_backend_completion.sql) 为准；同时增加 SSH 公钥校验字段 `host_key TEXT` 与工单执行人、时间、JSON 结果、错误字段。会话、撤销与在线状态存储在 Redis，以会话剩余有效期设置 TTL。

`0014_query_shares_tickets.sql` 新增 `sys_query_shares`（令牌哈希、所有者、JSON 快照、1–30 天期限、撤销、访问次数）和工单审批人；工单状态扩展为 pending/approved/rejected/executing/executed/failed。

`0015_export_requests.sql` 新增 `sys_export_requests`（申请人、目标连接、CSV/JSON 格式、行数、原因、JSON 快照、审批状态、审批人和创建时间），下载限定本人或管理员且必须批准。`0016_rebuild_ast_lineage.sql` 清除旧正则推测的 SQL 边缓存，保留外键与其他资产边，从成功查询历史重新解析 AST。

DBHub 的元数据存储采用 PostgreSQL (推荐 v14+)。本设计专注于系统自身的配置管理、用户权限及审计日志，不包含用户连接的目标数据库结构。

## 2. DDL 建表脚本

### 2.1 基础配置与扩展

```sql
-- 启用 UUID 扩展（可选）
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- 创建更新时间触发器函数
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ language 'plpgsql';
```

### 2.2 用户与权限 (`sys_users`, `sys_roles`)

```sql
CREATE TABLE sys_roles (
    id SERIAL PRIMARY KEY,
    code VARCHAR(50) NOT NULL UNIQUE, -- admin, developer, readonly
    name VARCHAR(100) NOT NULL,
    description TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE sys_users (
    id BIGSERIAL PRIMARY KEY,
    username VARCHAR(64) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    email VARCHAR(255),
    role_id INT REFERENCES sys_roles(id),
    is_active BOOLEAN DEFAULT TRUE,
    last_login_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TRIGGER update_sys_users_modtime 
    BEFORE UPDATE ON sys_users 
    FOR EACH ROW EXECUTE PROCEDURE update_updated_at_column();
```

### 2.4 数据库连接配置 (`sys_connections`)

CREATE TABLE sys_connections (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES sys_users(id) ON DELETE CASCADE,
    ssh_tunnel_id BIGINT REFERENCES sys_ssh_tunnels(id) ON DELETE SET NULL,

    type VARCHAR(20) NOT NULL CHECK (type IN ('mysql', 'postgres', 'redis', 'mongo')),
    
    -- 连接详情

    database VARCHAR(100), -- 默认数据库

## 3. 安全策略


### 3.1 敏感数据加密
所有涉及密码、私钥的字段（`private_key`, `passphrase`, `password`）**严禁明文存储**。
- **加密算法**: AES-256-GCM
- **密钥管理**: 密钥应通过环境变量 `APP_SECRET_KEY` 注入，不得写入代码或数据库。

### 3.2 连接池管理
后端 Go 服务应维护所有活跃数据库连接的连接池。
- **空闲超时**: 300s
- **最大生命周期**: 3600s
- **最大连接数**: 根据实例规格动态调整


## 连接器目录与自定义数据源（0021）

驱动制品不可变，模板修订追加发布；停用通过 enabled，不重绑既有实例。外键默认 RESTRICT，禁止删除被引用版本。数据源实例以 template_revision_id 固定模板及驱动，parameters 仅保存非敏感结构化字段，口令沿用 sys_connections.password 加密。以下 DDL 与迁移一致：

```sql
-- Immutable driver artifacts and template revisions. State may be disabled, never rebound.
CREATE TABLE sys_jdbc_drivers (
 id BIGSERIAL PRIMARY KEY,
 artifact_id VARCHAR(120) NOT NULL UNIQUE,
 name VARCHAR(100) NOT NULL,
 version VARCHAR(80) NOT NULL,
 class_name VARCHAR(255) NOT NULL,
 sha256 CHAR(64) NOT NULL,
 enabled BOOLEAN NOT NULL DEFAULT true,
 created_by BIGINT NOT NULL REFERENCES sys_users(id),
 created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE TABLE sys_datasource_templates (
 id BIGSERIAL PRIMARY KEY,
 template_key VARCHAR(80) NOT NULL,
 revision INTEGER NOT NULL CHECK(revision > 0),
 name VARCHAR(100) NOT NULL,
 product VARCHAR(80) NOT NULL,
 driver_id BIGINT NOT NULL REFERENCES sys_jdbc_drivers(id),
 dialect VARCHAR(20) NOT NULL DEFAULT '' CHECK(dialect IN ('','mysql','postgres')),
 url_template TEXT NOT NULL,
 fields JSONB NOT NULL CHECK(jsonb_typeof(fields)='array'),
 enabled BOOLEAN NOT NULL DEFAULT true,
 created_by BIGINT NOT NULL REFERENCES sys_users(id),
 created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
 UNIQUE(template_key, revision)
);
CREATE INDEX idx_datasource_template_driver ON sys_datasource_templates(driver_id);
ALTER TABLE sys_connections DROP CONSTRAINT sys_connections_type_check;
ALTER TABLE sys_connections ADD CONSTRAINT sys_connections_type_check CHECK(type IN ('mysql','postgres','redis','mongo','jdbc'));
ALTER TABLE sys_connections ADD COLUMN template_revision_id BIGINT REFERENCES sys_datasource_templates(id);
ALTER TABLE sys_connections ADD COLUMN parameters JSONB NOT NULL DEFAULT '{}'::jsonb CHECK(jsonb_typeof(parameters)='object');
ALTER TABLE sys_connections ADD CONSTRAINT connection_template_kind CHECK((type='jdbc')=(template_revision_id IS NOT NULL));
CREATE INDEX idx_connection_template ON sys_connections(template_revision_id);
ALTER TABLE sys_meta_snapshots ADD COLUMN metadata_status JSONB NOT NULL DEFAULT '{}'::jsonb;
```
