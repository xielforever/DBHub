## 统一运行入口

从仓库根目录执行。需要 Docker Compose、Python 3；Go/Node 在固定版本的 Docker 中运行。首次环境安装按 [Cloud README](../../scripts/cloud/README.md) 执行。所有档位使用真实 PostgreSQL、MySQL、Redis、JDBC，自动启动缺少的开发依赖，复用独立随机测试 Schema，不使用 Mock。

```sh
# 预览，不启动容器、不写报告
python3 scripts/cloud/regression.py --profile smoke --plan

# 日常：32 个关键 HTTP 顶层测试及其子测试，包含 JDBC 和权限安全边界，外加四套前端回归
python3 scripts/cloud/regression.py --profile smoke

# 提测/每次合并：后端全量竞态 + vet + Go 已导入包漏洞门禁，前端审计、回归及构建
python3 scripts/cloud/regression.py --profile full

# 发版：全量检查 + 从当前干净提交构建三个生产镜像 + 实际浏览器及故障/灾备验收
# 发布前按真实时钟执行 30 分钟，不用缩短 duration 替代
python3 scripts/cloud/regression.py --profile release --soak-seconds 1800 --clients 4
```

`release` 需要干净且已提交的工作区，不接受外部旧标签作为当前代码；镜像标签和 ID 写入汇总。它需要宿主 Playwright 1.62.0 和 Chromium，可提前执行 `python3 -m pip install playwright==1.62.0`、`python3 -m playwright install chromium`；Linux 缺依赖时按环境安装所需系统库。`DBHUB_CHROMIUM_PATH` 可指定系统浏览器，留空使用 Playwright 自带浏览器。

`release --soak-seconds 0` 可执行与 CI 相同的短版发布演练，**持续负载会明确标为未执行**。合成演练校验错误和回执差异为 0、资源清理成功；它输出延迟分布，不设置通用生产延迟门槛，不代替 G05 的真实业务容量验收。

运行入口会串行执行阶段并对同一状态目录加锁；失败即停止并返回非零码。Go 必需测试缺失、意外跳过、空前端测试、验收未完成、临时资源未清理，均不能算通过。完整 Go 测试允许的专用跳过只有子进程辅助入口、独立版本矩阵和 openGauss 演示；汇总保留跳过原因。后两项按下列独立入口执行：

```sh
python3 scripts/cloud/compatibility.py
python3 scripts/cloud/opengauss-demo-check.py
```

不要与版本矩阵、其他 Go 测试或 backend/JDBC 重建并行。测试会执行写入、撤权、停测试依赖及恢复操作，仅用于专用开发/回归环境。故障脚本操作自己创建的容器；不要把 wrapper 指向生产 Compose、生产数据卷或真实业务实例。

结果保存在 `${DBHUB_STATE_DIR:-/workspace/dbhub-cloud}/regression-artifacts/<时间及提交>/summary.json`。它记录源提交、工作区指纹、阶段结果、用例数量、跳过项、镜像 ID、独立验收证据位置和未覆盖范围；`completed=true` 表示所选档位通过，`production_approval=not_evaluated` 明确表示尚未完成生产准入决策。同目录原始日志权限受私有状态目录保护，可能含测试诊断信息，不能直接对外分享。CI 只上传汇总和无敏感内容的 `checks.json`。

依赖服务及缓存保留，避免停止正在使用的开发环境；独立发布验收容器/卷/凭据由各脚本清理。候选镜像保留供复核，可按汇总中的精确标签逐个删除；不要执行全局 prune。异常中断后先核查本轮资源再重试。

## 自动化业务矩阵

| 用例组 | 优先级 | 场景与必须结果 | 自动化入口 |
| --- | --- | --- | --- |
| 身份及空间 | P0 | 跨空间已知 ID 仍拒绝；撤销后恢复成员也不能复用旧事务/执行身份；切空间清空旧数据 | `TestWorkspaceIsolation`、`TestMembershipRevokeRestoreInvalidatesOldQueryAndTransaction`；dashboard 浏览器 |
| 目录及凭据 | P0 | 共享目录可见不等于能执行；各用户配置自身账号，其他用户及管理员不能读出个人口令；用户组撤权立即生效 | `TestPersonalConnectionIsolation`、`TestSourceAudienceAndDirectory`、`TestSourceBindConcurrentRevocation` |
| 检查及采集 | P1 | 错误口令/超时/取消有明确结果；并发编辑不覆盖新配置；失败采集保留上一次完整快照 | `TestDatasourceReliability`、`TestMetadataSyncReliability`、`TestSourcePolicyConcurrentUpdates` |
| 驱动及修订 | P0 | JDBC 真连接、限时、只读；禁用驱动阻止新访问及已有事务提交；更换修订不保留旧检查结果 | `TestConnectorJDBCRealHTTP`、`TestSourceRevisionGovernance` |

## 人工业务验收与交付

[人工回归模板 CSV](../acceptance/regression-uat-template.csv) 可直接导入表格。初始执行状态均为“待执行”，不能将自动化结果复制成目标组织的 UAT 结果。

准备两个工作空间 W1/W2；发布者 A、独立管理员审阅者 B、普通查看者 C、无权限用户 D，以及新获受众权限的审阅者 E。为“库存”准备各用户独立数据库账号和受限只读报表账号；D 不属于任何获权组。使用脱敏样本和临时测试表，记录测试对象 ID，测试完成后清理。

发布记录须包含候选提交/镜像摘要、环境、G01–G09 的责任人及证据、自动化汇总、人工 CSV、已知限制、容量目标与实测值、恢复目标与实测值、回退命令及联系人。任何 P0 未通过、必测项跳过、回执对账不一致或恢复无法确认均阻断发布；先修复并重跑受影响用例，再按变更范围决定全量复验。

灰度后先验证入口、登录、已授权报表/看板读取、无权用户拒绝、通知与审计落库及备份新鲜度。生产中不执行回归脚本的故障注入和业务表写入；观察既定指标后再扩大用户范围。
