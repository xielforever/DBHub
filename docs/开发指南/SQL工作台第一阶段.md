SQL 工作台第一阶段

工作流：选择已有连接和数据库 → 编辑 SQL → 按需格式化 → 运行 → 查看结果或错误。

默认操作只有“运行”和“格式化”，执行中提供“取消”。页面使用单编辑器和单个在途请求，结果始终标注执行时的连接、数据库和 SQL。支持选中执行与 Ctrl/Cmd + Enter；未选中时运行编辑器全部内容，每次仅允许一条 SQL。

保留的功能：

- 选择已有 PostgreSQL/MySQL 连接与数据库，显示生产环境和只读状态。
- 复用 Monaco 提供语法高亮、撤销和快捷键；加载失败时使用基础编辑器。
- 根据连接类型选择格式化方言；格式化失败保留原 SQL，格式化可撤销。
- 展示查询行、写入影响行数、耗时、错误和实际返回行数对应的截断提示。
- 保留行虚拟滚动与同一表格内的横向滚动，使用稳定列下标支持重复列名。
- 延续服务端角色权限、只读保护、超时、返回行数限制，以及生产写操作的执行确认。

暂缓的功能：多标签、手动事务、参数面板、浏览器队列、AI、EXPLAIN 和计划分析、统计、快照、对比、历史、收藏、导出、分享、报表保存、协作和策略配置面板。相关组件不在工作台挂载，不发起自动请求，不读取或写入原工作台的 SQL、参数和结果缓存。现有后端接口和其他业务页面保留。

执行边界：

- 在请求发出前固定连接、数据库和 SQL；运行中锁定执行目标，编辑器后续输入不改变在途请求或结果归属。
- 重复按钮或快捷键调用不会自动排队；取消只针对当前请求，取消期间继续阻止新请求，取消后到达的响应不会显示为成功。
- 离开页面会中止请求并忽略后续响应；数据库列表请求也会在切换连接时中止并忽略过时响应。
- 普通执行不自动加入同账号已有事务。调用保留的事务接口时，后续执行须显式传入事务 ID；无效 ID 不关闭原有事务。
- 不追加字符串形式的 LIMIT，服务端限制返回结果；第一阶段请求上限为 1000 行、30 秒，并服从服务端更严格的设置。

