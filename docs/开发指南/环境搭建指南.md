# 开发环境搭建指南

## 1. 前置准备

在开始开发 DBHub 之前，请确保您的工作环境满足以下要求。我们推荐使用 **Docker 容器化** 方式进行开发，以确保环境一致性。

### 1.1 必备工具
- **Git**: 版本控制工具。
- **Docker Engine**: v20.10 或更高版本。
- **Docker Compose**: v2.0 或更高版本。
- **代码编辑器**: VS Code (推荐) 或 GoLand/WebStorm。

### 1.2 推荐 VS Code 插件
- **Vue - Official**: 提供 Vue 3 语法高亮与智能提示。
- **Go**: Google 官方 Go 语言插件。
- **Tailwind CSS IntelliSense**: 智能提示 CSS 类名。
- **ESLint / Prettier**: 代码格式化。

## 2. 获取代码

```bash
# 克隆仓库
git clone https://github.com/your-org/dbhub.git

# 进入项目目录
cd dbhub
```

## 3. 环境变量配置

复制示例配置文件并进行调整：

```bash
cp .env.example .env
```

`.env` 文件核心配置说明：

```ini
# Docker 镜像版本
FRONTEND_IMAGE_VERSION=node:24.12.0-bullseye
BACKEND_IMAGE_VERSION=golang:1.25.5-alpine3.23

# 服务端口
FRONTEND_PORT=5173  # 前端访问端口
BACKEND_PORT=8080   # 后端 API 端口

# 应用环境
APP_ENV=development
```

## 4. 启动开发环境

我们提供了一键启动脚本（基于 Docker Compose）。

```bash
# 启动所有服务 (后台运行)
docker compose up -d

# 查看容器运行状态
docker compose ps
```

首次启动可能需要几分钟来拉取镜像和安装依赖。

## 5. 访问与验证

服务启动成功后：

- **前端页面**: 访问 [http://localhost:5173](http://localhost:5173)
- **后端 API**: 访问 [http://localhost:8080/api/health](http://localhost:8080/api/health)
- **从容器日志查看输出**:
    ```bash
    # 查看前端日志 (实时)
    docker compose logs -f frontend
    
    # 查看后端日志 (实时)
    docker compose logs -f backend
    ```

## 6. 开发模式说明

### 前端开发
前端容器挂载了本地的 `frontend/src` 目录。
- **热重载 (HMR)**: 修改 Vue 文件后，浏览器会自动刷新。
- **依赖管理**: 如需安装新包，请在容器内执行：
    ```bash
    docker compose exec frontend npm install <package-name>
    ```

### 后端开发
后端容器配置了 `Air` 热加载工具。
- **自动编译**: 修改 `.go` 文件后，Air 会自动检测并重新编译重启服务。
- **调试**: 建议通过日志查看 API 输出和错误堆栈。

## 7. 常见问题排查

**Q: 容器启动失败，提示端口被占用？**
A: 修改 `.env` 文件中的端口号，或者停止占用该端口的本地服务。

**Q: 依赖安装速度慢？**
A: 可以在 Dockerfile 中配置国内镜像源（如阿里云/清华源）。

**Q: 后端连不上数据库？**
A: 确保在 Docker 网络内部使用服务名（如 `postgres`）而不是 `localhost` 进行连接。
