## 2 执行与数据边界

- 元数据库连接池服务DBHub自身。普通目标请求按需独占连接并在结束后关闭，显式事务持有专用连接；尚无跨请求长期复用的统一目标连接池。
- SQL结果按上限收集后返回有界JSON，当前不提供通用前端流式结果接口。通知/待办按既有接口实现，不承诺所有操作都有WebSocket。
- 个人操作解析本人连接；正式内容解析获准受管账号。角色许可、内容受众、原数据上限和执行身份分别检查。
- 写操作保留发送前登记、幂等回执和未知结果核实。取消或通信失败不表示业务事务已经回滚。
- 权限基础已有隔离实现，真实权限未切换；统一部门数据规则、完整新审批及团队交付按当前路线分期，不新增通用IAM或工作流平台。

## 3 前端职责

技术栈为Vue 3、TypeScript、Vite、Vue Router、Pinia、Element Plus、Tailwind CSS和ECharts；具体版本以[package.json](../../frontend/package.json)及锁文件为准，不维护历史构建体积或写死版本副本。

| 位置 | 职责 |
| --- | --- |
| [router/index.ts](../../frontend/src/router/index.ts) | 路由、登录与工作空间上下文、当前许可检查及同权旧链接 |
| [stores/user.ts](../../frontend/src/stores/user.ts) | 身份、空间、能力快照、有效来源及切换时失效处理 |
| [layouts/](../../frontend/src/layouts/) | 旧布局、按启用状态选择的自适应布局及动态权限菜单 |
| [api/](../../frontend/src/api/) | 已有请求封装和业务接口，不在组件重复拼装同一协议 |
| [views/](../../frontend/src/views/) | 报表、仪表盘、工作台、连接、治理及其他业务页面 |
| [components/](../../frontend/src/components/) | 通用组件与已有图表复用，结合本次功能抽取必要公共部分 |

前端按当前路由、Store、布局和业务组件组织；公共部分在实际复用时抽取。

### 3.1 权限与请求状态

新权限界面按启用范围使用服务端许可目录和当前快照，旧模式继续兼容。菜单、路由和按钮不能替代服务端授权。跨空间切换须清理旧结果、取消旧请求并防止迟到响应覆盖新上下文；无空间、无菜单和独立本人/平台入口保持可达。

统一数据规则和新审批策略未实施时显示相应受限说明，不能用前端按钮开放尚无执行约束的能力。流程解释见[核心流程图](../项目管控/核心业务流程与状态图.md)，不在架构文档重复业务状态表。

### 3.2 组件与界面维护

复用现有API、类型、用户状态、EChart/ChartCard及业务组件，保持[UI设计规范](../界面设计/UI设计规范.md)中的主题和响应式约定。按本次功能覆盖加载、空数据、失败、无权限及键盘操作，不要求所有控件套用同一种缩放动画或固定像素布局。

路由懒加载与图表按需引入沿用现有配置；构建、测试与实际浏览器检查按任务选择。

Go版本及依赖以[go.mod](../../backend/go.mod)和vendor为准。路由采用标准库net/http，入口见[server/router.go](../../backend/internal/server/router.go)。
