# 后端架构设计 (Backend Architecture)

本文档详细描述 DBHub 后端的内部架构、分层设计及核心模块实现。

## 1. 代码组织结构 (Standard Go Layout)

遵循 Go 社区标准项目布局：

```
backend/
├── cmd/
│   └── server/             # 程序入口 main.go
├── internal/               # 私有应用代码
│   ├── api/                # HTTP 处理器 (Handlers)
│   │   ├── auth/           # 认证相关接口
│   │   ├── connection/     # 连接管理接口
│   │   └── query/          # SQL 查询接口
│   ├── config/             # 配置管理 (Env/Viper)
│   ├── core/               # 核心业务逻辑 (Services)
│   ├── db/                 # 数据库访问层 (Repository)
│   │   ├── migrations/     # 数据库迁移脚本
│   │   └── models/         # 数据模型定义
│   ├── middleware/         # HTTP 中间件 (Auth, Logger, CORS)
│   └── ssh/                # SSH 隧道管理模块
├── pkg/                    # 可复用公共库
│   ├── crypto/             # 加密工具
│   ├── logger/             # 日志工具
│   └── response/           # 统一响应封装
└── go.mod                  # 依赖定义
```

## 2. 核心模块详解

### 2.1 连接管理器 (Connection Manager)

负责管理用户到目标数据库的物理连接。

- **连接池化**: 针对每个用户配置的数据源，后端维护一个独立的连接池 (`*sql.DB` 或 Native Driver Pool)。
- **生命周期**:
    - **创建**: 首次请求时懒加载创建。
    - **保活**: 定期发送 Ping 包。
    - **销毁**: 闲置超时 (Default: 10m) 或用户显式断开。
- **安全性**: 密码在内存中短暂驻留，仅在建立连接时解密。

### 2.2 SSH 隧道服务 (SSH Tunnel Service)

允许用户通过跳板机访问内网数据库。

- **实现原理**: 使用 Go 的 `golang.org/x/crypto/ssh` 包建立 SSH Client，并通过 `Dial` 方法进行端口转发。
- **复用机制**: 多个数据库连接可复用同一个 SSH 会话。

### 2.3 SQL 执行引擎

- **参数化执行**: 强制使用 Prepare Statement 防止 SQL 注入。
- **结果集流式处理**:
    - 对于 `SELECT` 查询，不一次性加载所有 Rows 到内存。
    - 使用 `json.Encoder` 结合 `http.ResponseWriter` 逐行输出 JSON 数组，实现流式响应。

### 2.4 认证与授权

- **JWT 认证**:
    - Access Token (短效，15分钟)
    - Refresh Token (长效，7天)
- **RBAC 模型**: 基于 Casbin 或自定义中间件实现基于角色的接口访问控制。

## 3. 错误处理规范

所有业务错误必须统一封装，包含错误码和对用户友好的错误信息。

```go
type AppError struct {
    Code    int    `json:"code"`
    Message string `json:"message"`
    Err     error  `json:"-"` // 内部错误堆栈，不暴露给前端
}
```

## 4. 日志规范

使用结构化日志 (Structure Logging / slog)。

- **Info**: 常规请求日志 (Request ID, IP, Latency)。
- **Warn**: 业务异常 (如登录失败、权限被拒)。
- **Error**: 系统异常 (如数据库连接断开、Panic)。
- **敏感信息过滤**: 日志中严禁打印密码、私钥、Token 等敏感字段。
