# 前端架构文档

DBHub 前端基于 Vue 3 生态构建，强调高性能交互与"液态玻璃"视觉风格。

## 1. 技术栈详细

- **框架**: Vue 3.x (Composition API, `<script setup>`)
- **构建工具**: Vite 4.x
- **语言**: TypeScript (Strict Mode)
- **状态管理**: Pinia
- **路由**: Vue Router 4.x
- **样式**: Tailwind CSS v4 + PostCSS
- **UI 组件**: Element Plus (按需引入)
- **图标**: Element Plus Icons + Lucide Vue
- **可视化**: Apache ECharts 5.x
- **动画**: GSAP (复杂动画) + CSS Transitions

## 3. 状态管理 (Pinia)

### 3.1 Store 设计

我们不使用单一的大 Store，而是根据业务领域拆分：

- **AuthStore**: 管理登录状态、Token、用户信息。
- **ConnectionStore**: 管理左侧树状连接列表、当前激活的数据库连接。
- **TabStore**: 管理右侧工作区打开的标签页（如查询窗口、表结构设计器）。

### 3.2 示例代码

```typescript
// stores/connection.ts
import { defineStore } from 'pinia'
import { ref } from 'vue'

export const useConnectionStore = defineStore('connection', () => {
  const activeConnectionId = ref<string | null>(null)
  const connectionList = ref<Connection[]>([])

  async function refreshList() {
    // 调用 API 获取最新列表
  }

  return { activeConnectionId, connectionList, refreshList }
})
```

## 4. 样式系统与设计与实现

### 4.1 液态玻璃风格实现机制
- **背景**: 使用 Tailwind 的 `bg-gradient-to` 或自定义 CSS 变量创建多层径向渐变。
- **卡片**: 统一使用 `.glass-card` 类，封装了 `backdrop-blur`, `bg-opacity`, `border` 等属性。
- **交互**: 所有可点击元素必须包含 `active:scale-95` 和 `hover:brightness-110` 等微交互反馈。

### 4.2 Tailwind v4 集成
直接在一个 CSS 文件中通过 `@import "tailwindcss";` 引入，并在 `@theme` 块中定义项目专属的设计 Token（颜色、阴影）。

## 5. 性能优化策略
- **路由懒加载**: 所有路由页面必须使用 `() => import(...)` 方式引入（含 /tickets /proxies /assets）。
- **组件按需加载**: Element Plus 使用 `unplugin-vue-components` 自动按需导入；`DataLineagePane / PerformanceMonitorPane / ChangeTicketPane` 三件套跨页复用，不复制。
- **ECharts 按需引入**: 仅引入使用到的图表类型和组件，避免整包体积过大（`EChart` 548kB 单独 chunk）。
- **构建拆分**: `vue-tsc -b && vite build` 输出 `QueryView ~261kB / DashboardView ~90kB / TicketView ~13kB`，按路由自动 code-split。

## 6. 关键交互约定（Step20-24 收口）

- **导航一一对应**：`MainLayout.vue menuGroups` 手写分组（概览/数据/安全），每项 `to` 与 `router/index.ts` 完全一致，无假链接；`Ticket` 与 `Waypoints` 新增后已同步。
- **暗色玻璃**：所有 `el-select / el-dialog / dropdown` 使用 `glass-popper / glass-dialog`（`rgba(16,22,40,.97)` + `backdrop-blur`），新增工单/报表/代理弹窗一致。
- **自适应**：资产列表 `min-w-[1080px]` + 横向滚动，工单中心响应式栅格（5 KPI → 2 列），Dashboard 监控 `h-[520px]` 内滚动。
- **血缘→工单**：`DataLineagePane @create-ticket` → `router.push /tickets?table=&db=` → `TicketView prefill` 自动建单，示例 `ALTER TABLE {{table}}`。
- **监控→工作台**：`PerformanceMonitorPane @reuse` → `/query?sql=` 重放。
- **另存报表**：`QueryView` 工具栏 `BookmarkPlus` → `reportApi.create` 固化 `connection_id/database/sql/chart_type/chart_config`。
