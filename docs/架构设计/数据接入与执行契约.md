# 数据接入与执行契约

更新日期：2026-10-24。适用于数据管理、我的连接、数据工作台、数据目录及其执行/审计链路。本文统一维护数据接入、权限治理、执行可靠性、采集、兼容和审计的有效规则。

当前已有相关实现，产品剩余验收见[路线图](../项目管控/开发路线图与当前任务.md)。已实现、待验收和后续规划分别标明，不由规则描述推断功能已验收或真实启用。接口字段在[API规范](../接口规范/API接口规范.md)维护，结构升级在[数据库设计](../数据库设计/数据库模型设计.md)及增量迁移维护，本文只维护跨接口执行规则。

## 1 数据源、身份与能力

| 对象 | 必须保持的边界 |
| --- | --- |
| 驱动与模板 | 可信制品及校验值由部署清单固定；驱动登记、模板发布与使用许可分开。模板修订追加发布，实例固定修订，不引用浮动“最新版本” |
| 共享定义 | 提供已授权目标及规则，不携带发布者的个人密码、私钥或会话；个人/空间归属分别检查 |
| 我的连接 | 服务端按当前主体解析本人数据库身份；编辑空口令按原保留/清除协议处理，不把未保存配置写入现有连接 |
| 正式执行账号 | 只供获准报表等受管路径使用，不转为个人连接或通用源库读取权；账号、来源修订、数据库及凭据代次受原批准约束 |
| 连接器能力 | SQL、格式化、元数据、完整采集、键值、事务及强制只读分别判断；能连接不等于所有能力可用。未知产品/方言不默认落到PostgreSQL |

原生MySQL/PostgreSQL、Redis键值及可选JDBC沿已有适配器执行。Go负责认证、空间/对象权限、AST/行列策略、准入、发送前登记、回执和审计；Java仅执行已授权JDBC操作及类型转换，不读取DBHub元数据库，不允许终端用户直接调用。SQL、预览、报表、工单和导出复用连接器运行时。

JDBC内部协议和部署制品见[jdbc-runner](../../services/jdbc-runner/)。普通查询结果上限10000行、默认1000行，结果行JSON预算8MiB；受管大结果/导出沿独立批准及更严格上限，不由普通接口启用。JDBC协议、租约、会话及建连限制保持现有实现；不能仅凭驱动类启用SQL、事务或完整采集。凭据不进入URL、公开DTO、日志或导出载荷，内部服务按既有网络/TLS约束部署。驱动/模板停用阻断后续新会话，不宣称已经中断目标上全部在途操作。

## 2 请求与目标会话

每次请求绑定当前主体、原空间、连接/定义修订和操作，不接受客户端自报角色或可信授权版本。功能许可、连接器能力、对象范围、原数据上限、字段输出与执行身份均须满足；缺失、过期、冻结、撤权或加载失败时停止相应动作。当前前后端判定流程见[核心流程图](../项目管控/核心业务流程与状态图.md)。

元数据库使用独立连接池。普通目标请求按需持有独占会话并在结束后释放；显式事务固定同一物理连接、按原空闲期限清理，不将普通执行自动加入已有事务。连接关闭使用独立清理上下文；取消是尽力操作，不保证目标立即停止。当前不建设跨请求目标连接池、共享SSH会话池或通用流式结果协议。

SQL日常入口保持运行、格式化和执行中取消。发送前固定目标、数据库及SQL；后续编辑不改变在途请求归属。重复按钮/快捷键不自动排队；切连接、离页或切空间时取消请求并忽略迟到响应。保留后端高级接口不等于恢复全部早期工作台面板。

应用值参数化，动态标识符验证或安全引用；用户SQL经过支持方言的AST和原误写检查。无WHERE或明显恒真写入按原策略拦截，但有WHERE不证明影响范围安全，返回行数上限也不限制写入影响行数。新业务查询默认只读；写操作经固定业务办理或SQL工单，维护例外须独立批准目标、账号、动作和期限。旧合法SQL/Redis写动作按兼容清单保留，不静默新增或删除。

## 3 发送前登记、回执和未知结果

执行请求使用唯一编号；同一主体、空间/执行路径和编号只能取得一次登记后的执行机会。请求内容、参数、选项或身份边界变化不得复用编号；新编号是新执行，不用SQL文本去重。元数据登记、当前权限检查、准入及running持久化成功后才发送SQL。

| 回执 | 含义 |
| --- | --- |
| queued | 已登记，尚未发送用户SQL，等待检查或准入 |
| running | 开始状态已持久化，可能已经发送SQL |
| succeeded | 获得目标成功响应；事务内仅表示语句完成，不代替提交 |
| rejected | 未向目标发送用户SQL |
| failed | 确定的语句拒绝或未完成只读查询 |
| unknown | 结果无法确定，可能已提交，保留原编号并核实目标 |

超时、取消、通信中断或提交确认丢失不能自动解释成回滚。回执写入与HTTP取消分离；无法确认时不自动重发SQL。进程失联的过期状态按原协议转为待确认，迟到的确定结果仍可更新回执，不能释放编号供再次执行。

浏览器会话存储只保留按主体隔离的待确认编号，不保存SQL、参数或结果行；存储失败时不能冒险发送。刷新/重进页面先核实原编号；404也不能证明原请求未登记。回执只返回本人获准摘要，查询完成摘要不冒充已恢复全部结果行。

现有防重主要覆盖普通查询执行，不能推断所有API均有恰好一次语义。查询登记记录不通过TTL或历史清理删除后重用；后续归档也必须保留防重键或等价拒绝能力。元数据库与外部目标不共享原子提交协议；单进程并发/等待限额也不能宣传为分布式调度。容量、超时、字节和行数约束沿调用路径现有更严格上限执行，不另建一套配额规则。

## 4 检查、采集与持久任务

只有声明并验证完整采集能力的路径可清理过期元数据。须完整读取本轮规定库、Schema和对象后，在同一元数据事务内发布快照和清理；部分失败、取消、修订变化或锁冲突保留原快照。提交确认丢失标为unknown，不断言旧快照仍在。通用JDBC结构浏览不等于完整采集，Redis等不支持的采集明确跳过。

同源采集沿原互斥规则执行。当前页面通过持久任务显示进度，旧同步接口不成为另一套实现入口。任务固定空间、操作者、成员与连接修订，不保存口令，不借用他人连接；执行、发布及结果读取重查当前资格、租约和取消状态。排队取消立即处理，运行取消尽力发送，已提交快照不回滚。

当前源任务的有界规则如下，复用[现有队列](../../backend/internal/db/source_task_repo.go)与[维护服务](../../backend/internal/automation/service.go)，不推广为普通SQL的分布式配额：

| 项目 | 当前约束 |
| --- | --- |
| 活动记录 | 同一连接同一种任务仅一个；每人最多10个、每空间100个、平台200个 |
| 并发与租约 | 同一元数据库下跨实例合计最多运行2个源任务；运行最多4分钟，租约5分钟 |
| 定时计划 | 检查最短5分钟，采集最短60分钟；只操作创建者自己的连接，同源忙时跳过，不补跑停机期次 |
| 发布 | 快照发布与任务成功在同一事务检查租约和取消；提交后不回滚，确认丢失按unknown核实 |

中断/超期租约不自动重放，人工重试创建新任务并保留旧记录。定时计划沿原最小间隔和去重规则，不补跑停机期间积压；角色、授权、配置变更或退出使相关旧任务/计划失效，不能沿用原快照继续运行。

连接检查结果与配置修订关联；版本未知、无查询版本权限、检查失败及未配置分别表达，不能把旧检查显示为当前在线。兼容性支持以[实测矩阵](../../backend/internal/target/compatibility_matrix.json)及其证据的版本、环境和能力范围为准，一个连接成功不推广为TLS/SSH、所有补丁或全部SQL均已验证。

## 5 审计与恢复

受审计动作进入执行前，必须完成可靠登记及已验证身份/目标快照；登记或必要快照无法持久化则拒绝动作。结果可靠持久化后幂等补写元数据库；补写只重放日志，不重新执行SQL、提交事务、发送取消或再次交付文件。

当前使用每后端副本独占的私有审计目录与文件锁、双槽校验、同步写入、事件UUID和数据库幂等补写。结果损坏/进程中断按实际证据恢复unknown；执行前记录损坏时保留现场并阻止不安全启动。队列满/存储失败按原503及就绪规则处理，不伪装健康。已执行后记录失败不得触发再次执行。

审计保存主体、空间、对象/目标身份、路由模板、事件时间、请求/任务/事务编号与状态；不记录口令、令牌、SQL/参数正文或业务结果。取消请求已发送不等于原执行已取消；下载响应已返回不证明接收方完整收到文件，响应失败不能改写已确认的SQL结果。

元数据库备份不能替代尚未补写的审计卷备份；重建和迁移保留对应私有卷。审计校验不提供不可篡改存储、目标库行级审计或跨库分布式原子性；普通成功只读请求的覆盖按既有审计规则，不在本次扩展。

固定业务办理使用获准模板、账号、目标版本和前后摘要，申请、核验、执行及核实分别检查当前资格；stale或unknown不得自动重跑，按原operation_id核实。SQL工单使用原子领取和执行摘要，失败后人工核查，不能把普通查询的request_id回执协议套用于全部工单。接口及状态见[API规范](../接口规范/API接口规范.md)。

## 7 功能、治理与迁移的有效规则

### 7.1 许可、来源及可授予范围

功能许可只决定页面或动作，资源受众、数据范围、字段输出、执行身份和流程资格分别检查。角色使用稳定ID及版本，显示名不参与授权；一个空间可有多角色及直接/组来源。新增许可默认不加入已有角色或委派，未知/未实施许可不得启用；报表与仪表盘、业务办理与SQL工单、本人/空间/平台能力分别登记。

来源记录主体、角色/组、授予者、许可、对象/主体上限、期限和版本；撤销一个来源后仍解释剩余合法来源，撤尽才完全失权。角色复制、改名、停启、组扩员和无关联成员的新角色定义均不能绕过扩权判断。

可授予范围来自明确委派，不由“自己能执行”推导无限授予权。新增能力、角色启用、分配、组扩张、解除禁止和恢复旧来源先差异预览，再由非申请人、非受益人的当前合格人独立复核。双方委派、目标范围、有效期和基线均有效才原子应用精确差异；过期、冲突或审计/持久化失败不部分授予，无合格复核人保持暂停。重复请求幂等。

纯菜单显示可按显示管理资格调整，不增加许可。菜单隐藏不等于撤权，有权直达仍可用；真正撤许可后URL/API/数据层共同拒绝。首页依次取仍有效的本人选择、空间推荐、首个获准入口；无入口显示空状态。本人资料、安全、退出及获准平台入口不依赖业务空间；平台身份不自动成为空间成员。

### 7.2 旧权限逐主体兼容

| 旧来源 | 有效承接边界 |
| --- | --- |
| admin | 固定原端点动作、对象和数据上限，不自动获得新增数据、明文、团队交付、应急或平台能力 |
| developer | 保留本人分析、开发及原合法工具；已有SQL/Redis写动作单列，不自动获得复核、发布或账号维护 |
| readonly | 逐人/逐组选择业务查看或技术只读路径；未确认项完整保持原模式，不按名称批量转换 |
| report_review | 原报表/仪表盘复核、发布及导出复核逐动作映射；不补造历史数据复核签名或改写旧独立性 |
| datasource_manage | 源定义、账号、驱动及执行映射分别承接，不扩大为他人凭据、个人任务或全平台安装权 |
| audit_view / operation_review | 只承接原空间审计或固定业务核验，不附带平台审计、SQL工单审批、执行或写工具 |
| 平台管理标志 | 按原平台端点登记，不自动加入空间或取得业务数据；备份管理、恢复执行及治理恢复分开 |

实际映射逐空间、主体、来源、端点、对象、原账号/视图/行列约束和期限确认；类型表不是实际授权结果。个人查询与正式受管路径分别固定原数据身份，不从多角色中选“最强旧角色”。未知映射或原数据上限不明时不切换；不删除最后限制后伪称默认拒绝。

### 7.3 撤权、启用与回退

撤销、停用、到期和冻结先持久化收紧并递增版本；返回成功后的相关新检查均遵守收紧。旧JWT、前端快照、迟到响应及旧通知不能保活旧权。并发批准、发布、提交和撤权必须有事务顺序，不覆盖已确认收紧。收紧记录不可读时进入安全受限，恢复先核对当前收紧，不用旧快照兜底。

最后治理人的紧急冻结不能因缺少普通复核人而受阻。治理恢复须由两名不同的预登记身份完成当前密码及已启用MFA的实际核验，核对请求、名册和收紧代次；过期、重复或旧核验不能复用。恢复只授予最多15分钟的治理接续，通过后重新登录，到期停止，不恢复业务数据权、原角色/组、个人凭据、旧会话或订阅；完整资产接任按阶段3规划。

LEGACY_GUARDED保留原动作和数据上限并执行当前收紧；SHADOW仅只读比较，不执行影子写入、导出、订阅或送达；COMPAT_ACTIVE仅对原子配置包中已确认主体启用新功能模型，未确认主体各入口仍走原路径，无法隔离则空间不切换。差异未知不算通过，不允许无意扩权或未批准收窄，也不能新解析器拒绝后用旧admin兜底。

启用前固定空间、主体、配置/授权代次、原约束和恢复备份，检查所有API、数据库函数及worker的最低兼容桥接版本、路由指纹和任务版本，独立批准后原子切换；真实启用需另行明确授权。无关旧服务不能误执行新任务版本。

回退分配置、运行版本和结构恢复，不以破坏性降级DDL恢复旧数据库。目标须为认识增量结构并执行当前收紧的桥接版本；保留新表、旧签名、业务发布号、原文件期限、回执和审计，授权代次不倒拨。新模型独有对象及不等价新授权暂停保留，未知写入先核实，不自动重跑、续签或复活旧admin。回退不回滚业务库，不预先承诺零停机或无损。

## 8 已确认的数据执行目标（阶段2规划）

应用身份须与权威员工/负责人业务键、部门、仓库、运输组织及数据集/执行身份显式映射，记录来源、版本和有效期，不由相同数字ID、演示姓名或组名推导。不同数据集、部门和组织分别授权，工作空间与数据库不是业务范围的替代物。

一条允许规则保留完整条件；整条允许规则取并集，再与强制上限和动作范围求交并减明确禁止。不能把“华东且仓库A”和“华南且仓库B”拼成额外组合，不能把功能角色并集转换为更多数据。调岗、到期、禁止及原账号上限仍生效。

条件必须在关联、聚合和输出之前通过已支持的执行路径落实；复杂查询使用批准视图、目标库RLS或受控服务，不承诺任意SQL自动改写。不支持路径、未知映射、条件或分类时阻止相应数据动作。分类与展示、临时明文和交付的具体边界见[内容与交付契约](内容与交付契约.md#8-已确认的后续内容与交付规则)，不能以声明文字证明已执行。
